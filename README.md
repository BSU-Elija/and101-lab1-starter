# Hello Squirrel (Project 1)

## Overview

This project is a simple Android profile app that displays personal information such as name, bio, and hobbies. The goal of this project was to practice working with layouts, TextViews, and modifying UI elements.

## Features Implemented

* Updated profile name to **Elija Modesto**
* Added a personal bio describing interests and background
* Modified the hobby section to include three custom hobbies:

  * Coding
  * Working Out
  * Gaming

## Technologies Used

* Kotlin
* Android Studio
* ConstraintLayout
* XML UI Design

## What I Learned

* How to modify UI components using XML
* How to properly use ConstraintLayout for positioning elements
* How to connect UI design with app requirements
